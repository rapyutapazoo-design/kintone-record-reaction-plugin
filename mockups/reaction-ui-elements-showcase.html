リアクションボタン — 4種統一モックアップ

「PATTERN 01（単一・独立トグルボタン型）」と「PATTERN 02（複数リアクションピル＋クイックピッカー型）」の両方を、「いいね」「確認しました」「参考になった」「ありがとう」の4つのボタンに完全統一して比較できるモックアップです。

PATTERN 01 / DEDICATED TOGGLE BUTTONS 参考: X / note / Material Design 3

独立トグルボタン型（4種常時表示）

ピッカーを開かずにワンクリックで押せる独立ボタン設計。
「いいね」「確認しました」「参考になった」「ありがとう」の4つそれぞれに固有の配色とマイクロインタラクションを持たせています。

💡 パターン1の4種デザイン特徴：
・いいね（❤️ ピンク） / 参考になった（👍 ブルー）：SVGアイコンの線画→塗りつぶし変化＋放射パーティクル。
・確認しました（✓ エメラルドグリーン）：円が緑に塗りつぶされ、白抜きチェックマークがシュッと手書き風に描画。
・ありがとう（🙏 暖色グラデーション）：ローズ〜アンバーの柔らかいグラデーション背景＋お辞儀＆浮遊ハート（💖✨）。
パターン1の設計・CSS要素：
  • 4種の意味に応じたカラー設計： 共感＝ピンク（#e11d48）、業務確認＝エメラルド（#059669）、有益＝ブルー（#0969da）、感謝＝暖色グラデーション。
  • スロット式カウンター： 数字の増減時に上下へスライドし、font-variant-numeric: tabular-nums で横揺れを防止。

PATTERN 02 / REACTION PILLS & QUICK PICKER 参考: Slack / GitHub Primer / Discord

複数リアクションピル＋クイックピッカー型（4種統一）

同じ「いいね」「確認しました」「参考になった」「ありがとう」の4種をコンパクトなピル（Chip）と「😊＋」のクイックピッカーで扱う設計。ホバー時のツールチップや確認者アバター重なりを備えています。

💡 パターン2の4種デザイン特徴：
・ピルにマウスを乗せる（ホバー）と、「誰がそのリアクションを押したか」が吹き出しツールチップで表示されます。
・「✅ 確認しました」ピルには確認者のミニアバター（佐 田 あ）が重なって表示され、「🙏 ありがとう」ピルは暖色グラデーション＋浮遊ハート（💖✨）が発火します。
・カウントが 0 になったピルはバーから消え、「😊＋」ピッカー（4種）からいつでも再追加できます。
パターン2の設計・CSS要素：
  • ピルごとの4種テーマカラー： ピル型でも「❤️ いいね（ピンク）」「✅ 確認しました（グリーン）」「💡 参考になった（ブルー）」「🙏 ありがとう（暖色グラデーション）」のニュアンスを保持。
  • ソーシャルプルーフ（誰が押したか）： .tooltip によるメンバー一覧表示と、確認ピル内の .mini-avatar 重なり表示。

2. ステート（状態）設計のビジュアル一覧

4種のボタンすべてに共通する、ユーザーが「押せること」「押している瞬間」「自分が選択済みであること」を直感的に判断するための5つの基本ステートです。

① Default (未選択)

控えめなグレー枠と線画アイコン。まだ自分が押していないことが一目でわかる状態。

② Hover / Focus

背景がわずかに濃くなり translateY(-1px) で浮き上がる。キーボード操作時はフォーカスリングを表示。

③ Active (押下中)

クリックの瞬間に scale(0.93) で縮小し、物理ボタンを押した手応えを返す。

④ Selected (選択済み)

各ボタンのテーマカラーで塗りつぶされ、アイコンと枠線が強調されて選択済みを明示。

⑤ Disabled (無効)

アーカイブ済みレコードや権限外の場合に opacity: 0.45 と cursor: not-allowed で表示。
