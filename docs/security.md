# セキュリティ上の注意

- プロキシの GET 応答にはテーブルの全行が含まれます。DevTools で他人の記録が見える可能性があります（許容リスク）。
- 設定した API トークンの権限により、同じアプリ内の任意のレコードを書き換え得ます。トークンは「閲覧」「編集」のみに絞ってください。
- 押した人は `kintone.getLoginUser()` から取得するため、悪意のあるユーザーは他人名義で記録できます。
- アプリ管理者は `getProxyConfig` でトークンを読めます。
- `rx_label` は表示用で改ざんできます。画面表示は常に設定値を使い、`rx_key` を真実とします。
- 描画は `createElement` と `textContent` のみを使い、`innerHTML` は使いません。
- エラーメッセージとログには、応答本文・API トークン・ユーザー入力値を含めません（フィールドコードとエラーコードのみ）。
