# 手動テスト項目

**これは実機（kintone 環境）でしか確認できない項目です。** 自動テストでは検証できません。

## 最初に実施（前提の確認）
1. プロキシの疎通（PC・モバイルそれぞれで GET と PUT が通ること）。
2. モバイルで失敗した場合に、ボタンが無効になり案内文「モバイル版ではリアクションを付けられませんでした。PC 版の画面から操作してください。」が出ること。
3. event.record に権限のないフィールドが含まれないこと。テーブル・回数欄の閲覧権限がないユーザーで、回数と付けた人一覧が表示されないこと（押下後も表示されないこと）。
4. 部分更新の挙動: id 付きの既存行を 5 列だけで PUT したとき、既存の値が保たれること。

## 動作
- 付ける・取り消せる。
- 自分が付けたリアクションが、選択状態のトグルボタン（テーマ別の見た目）で表示される。
- 連打しても直列化され、整合した結果になる。
- 複数タブで同時に押しても競合時に再試行される。最終失敗時は表示が元に戻りエラーが出る。

## 見た目と演出
- 各ボタンに「アイコン・表示名・件数」が表示される（初期セットは いいね / 了解 / なるほど / ありがとう）。
- 未選択はグレー枠と線画アイコン、選択済みはテーマ色の塗りとアイコンの塗りつぶしになる（いいね＝ピンク、了解＝緑、なるほど＝青、ありがとう＝暖色）。
- 押して保存に成功したときだけ演出が出る（ポップ、粒の飛散。了解はチェックの描画、ありがとうはお辞儀と💖✨）。画面の初回表示や読み込み完了では出ない。
- 件数が増減するとき、数字が上下にスライドする。
- hover で少し浮き、押している間は縮み、無効時は薄くなり、キーボード操作ではフォーカスリングが出る。
- OS の「視差効果を減らす」をオンにすると、動きや粒が出ず、色の切り替えだけになる。
- 幅 480px 以下（スマホ）で、ボタンと「付けた人」の高さが 44px 以上ある。
- ヘッダーメニューに置いたとき、ボタンの高さや折り返しが崩れない。
- スペースフィールドに置いたとき、飛ぶ粒が親要素の枠で途中で切れない。
- 見た目が「絵文字」のボタンは、選んだ色（6色）で表示される。
- 選択済みの文字色のコントラストが読みづらくないか確認する（いいね・了解・ありがとうは基準の 4.5:1 に届かない。濃くするかはデザインで判断する）。

## 設定
- ボタンの停止・削除後も過去の記録が残り、表示と集計から除外される。
- 回数欄あり・なしの両方で表示が正しい。
- 配置先スペースを削除したとき、ヘッダーへフォールバックする。
- 設定画面で、見つからないスペースが「（見つかりません: …）」と表示される。
- 保存済みのキーを変更できない。
- リアクションが 12 件を超えて追加できない。
- 同じ show で二重描画されない。
- `.s.cybozu.com` 環境で動作する。
- 旧設定（like / favorite など）のアプリで「推奨セットを適用」すると4種になり、旧ボタンが無効で残る。
- 適用後に保存前に画面を閉じると設定は変わらない。
- 確認ダイアログでキャンセルすると何も変わらない。
- 12件を超える場合はエラーが出て適用されない。
- 推奨キーと同じキーの行が複数あると、エラーが出て適用されない。
- 適用後に保存してもキー変更エラー（「保存済みのキーは変更できません」）が出ない。
- 保存後にアプリを更新すると新しい見た目で表示され、過去の記録は集計に残る（like）。
